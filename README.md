# 🛍️ Product Quantity Selector – React

A modern and beginner-friendly Product Quantity Selector built using React JS and CSS. Users can increase or decrease product quantity and see the total price update automatically.

## ✨ Features

- 🛍️ Modern product card UI
- 🖼️ Product image and price
- ➕ Increase product quantity
- ➖ Decrease product quantity (minimum quantity: 1)
- 💰 Automatic total price calculation
- 🛒 Add to Cart button with confirmation message
- 📱 Responsive design

## 🛠️ Technologies Used

- React JS
- JavaScript
- CSS3
- Vite

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Tanishka2744/product-quantity-selector-react.git
   ```

2. Navigate to the project folder:

   ```bash
   cd product-quantity-selector-react
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
